## Contexto

Projeto acadêmico da disciplina de **Redes de Computadores da UFPel**, desenvolvido em equipe com **Rafael e Mauro**.

## Funcionalidades

Consulta de salas e laboratórios disponíveis, reserva de horários e visualização das reservas por data.

## Desenvolvimento

- **Next.js, React e TypeScript** no frontend.
- Servidor **Python com TLS** para a API de reservas.
- Persistência das reservas em arquivo **JSON**.

O projeto aplica conceitos de comunicação cliente-servidor, redes e integração de sistemas web.

[Ver documentação e código no GitHub](https://github.com/pepemesquita/Unireserva).
